# speech-paper-daily 单篇论文输出模板（唯一标准）

> 本文件是单篇论文精读输出的**唯一格式模板**。执行 skill 时必须先读取本文件，每篇论文严格按此模板输出，禁止省略任何字段，禁止改动结构。
>
> 字段分隔：一律使用中文冒号 `：`；同一行多字段用竖线 `|`。正文禁止 emoji，仅标题使用 📌 🔧 📊 ⭐。

```markdown
## [序号] 论文标题（英文原文）

**arXiv ID**：arXivID | **方向**：语音大模型 或 语音前端

**作者**：作者1, 作者2, 作者3

**机构**：机构名称（若无法获取写"arXiv未提供"）

**发布日期**：YYYY-MM-DD | **论文**：https://arxiv.org/abs/ID | **PDF**：https://arxiv.org/pdf/ID.pdf | **代码**：URL（无则"暂无"） | **Demo**：URL（无则"暂无"）

### 📌 简介
3-5句中文完整总结，让读者不看下文也能了解论文全貌。必须三要素齐全：①要解决的问题；②提出的方法/框架；③关键实验结果（含具体指标数值）。禁止只翻译摘要，必须基于全文提炼核心贡献。（200-300字符）

### 🔧 技术方案

**问题背景：** 该技术方案要解决的核心问题，现有方法/现有系统的局限性在哪里。基于论文Introduction提炼，而非重复摘要。（2-3句）

**模型架构：** 整体框架、关键模块名称与结构、模型规模（参数量/输入输出维度）、数据流。需体现专业深度，说出具体组件名与设计（示例：因果TFC-TDF U-Net、GRU、复数比例掩码等）。

**核心创新：** (1) 创新点1的详细技术说明（含实现细节，与现有方法的关键区别、为什么有效）。(2) 创新点2的详细技术说明。(3) 创新点3的详细技术说明。每个创新点2-3句。

**训练策略：** 损失函数、数据预处理、训练细节（数据集规模、训练轮数、学习率、优化器、batch size、混合精度、增强策略等具体数值），需从论文中提取具体值，禁止"待从全文补充"类占位。

### 📊 实验结果
**数据集**：数据集名称（含规模/采样率等关键信息）

**主要指标**：
- 指标1：具体数值（含单位/口径，如 cSDR、MOS、WER）
- 指标2：具体数值
- 关键对比：与最强基线相比提升多少（给出数值差）

**是否开源**：开源状况，如"代码已开源 @ https://github.com/xxx" 或 "暂无"（按论文实际信息填）

### ⭐ 评分：X/10
评分理由：基于论文实际内容的评价，覆盖创新性、实验充分性、实用价值等维度，3-5句，避免空泛套话。
```

## 格式硬性要求（违反即不合格）

1. **字段完整**：arXiv ID、方向、作者、机构、发布日期、论文/PDF/代码/Demo 六字段一个都不能缺；代码/Demo 无则填"暂无"
2. **中文冒号**：所有 `**字段名**：` 一律用全角冒号 `：`
3. **评分**：`### ⭐ 评分：X/10`（X为整数1-10）
4. **核心创新**：必须 (1)(2)(3) 编号格式；**主要指标**：必须 `- 指标：数值` 无序列表；禁止嵌套列表
5. **字符量**：单篇1500-2500字符；简介200-300；技术方案500-800；实验结果300-500；评分理由100-200
6. **禁止占位**：正文不得出现"待从全文补充""暂无信息"（代码/Demo字段除外）
7. **禁止翻译摘要式简介**：简介必须基于全文阅读提炼

## 评分锚点（参考）

| 分数 | 标准 |
|------|------|
| 9-10 | 突破性，顶会水准（Interspeech/ICASSP/NeurIPS） |
| 7-8  | 有实质贡献，实验较充分 |
| 5-6  | 增量工作，有参考价值 |
| 3-4  | 实验不足或方法普通 |
| 1-2  | 质量较低，建议跳过 |
